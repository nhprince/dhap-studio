Dhap Studio — Workflow Editor

One Project, Multiple Outputs

Dhap connects the original recording, extracted timestamps, human-edited instructions, vector annotations, and irreversible privacy redactions into a single portable .dhap bundle.

📄 Markdown Bundle

Standard GFM with relative asset directories, ready to commit directly to GitHub repository wikis and docs.

🌐 Standalone HTML5

Responsive single-page walkthrough with theme switching, sidebar navigation, and zero remote dependencies.

🔒 True Privacy Redaction

Solid blackout masks permanently destroy sensitive pixels on export; raw secrets cannot be recovered.

🎥

Non-Destructive Media Ingestion

Import any MP4, WebM, MOV, or MKV. Dhap keeps the source immutable while extracting keyframes and calculating timestamps.

🎯

Keyframe Scene Heuristics

Automatically suggests candidate steps based on scene transitions and activity pauses, giving you an immediate guide draft.

✏️

Vector Annotations & Badges

Add numbered badges, bounding boxes, directional arrows, and highlights. All annotations remain fully editable in the project.

🛡️

Preflight Privacy Checklist

Verify every step, broken asset link, and redaction zone before exporting. Irreversible baking destroys confidential data.

📦

The Portable .dhap Bundle

Self-contained ZIP package holding manifest, steps, and assets. Includes schema versioning and path traversal defense.

⚡

Automated CLI & MCP Ready

Inspect media, extract frames, and export documentation in headless CI/CD pipelines using the standalone dhap CLI.
